# 红豆算法模板 🫘

> ACM / ICPC 算法竞赛模板集，整理自日常训练与赛场实战。

参考 [WIDA](https://github.com/xiongwww/ICPC-Library)、[jiangly](https://github.com/thy233/ICPC-Library) 等选手的模板风格，结合个人习惯编写和维护。

---

```
红豆算法模板/

    ├── 基础算法.md                     — 二分、三分、离散化、倍增、排序、分治
    ├── 数据结构.md                     — 线段树、树状数组、并查集、平衡树、可持久化

    ├── 数学.md                         — 数论、组合数学、博弈论、多项式
    ├── 经典动态规划.md                  — 背包、区间 DP、数位 DP、状压 DP
    └── 杂.md                           — 字符串、计算几何、位运算、小工具
```

## 🧩 内容概览

### 竞赛框架
- 基础框架（自定义类型、常用宏、容器美化输出）
- 输入输出优化（快读、快写、关闭同步）
- 测试辅助（随机数据生成、对拍脚本）

### 基础算法
- 二分查找（左查找、右查找、浮点二分、单峰函数三分）
- 离散化、倍增、排序、分治

### 数据结构
- 线段树（普通、动态开点、李超、可持久化）
- 树状数组（单点改/区间查、区间改/区间查）
- 并查集（按秩合并、可撤销）
- 单调栈、单调队列、ST 表、珂朵莉树

### 图论
- 最短路（Dijkstra、Bellman-Ford、Floyd、SPFA）
- 最小生成树（Kruskal、Prim）
- 网络流（最大流、最小费用流、Dinic）
- 二分图匹配（匈牙利算法、KM）
- 树的直径、重心、LCA、树链剖分
- 强连通分量、割点、桥、2-SAT

### 数学
- 数论：gcd/exgcd、逆元、CRT、卢卡斯、莫比乌斯反演
- 组合数学：阶乘、组合数、容斥、卡特兰数
- 博弈论：SG 函数、Nim 游戏
- 多项式：FFT、NTT

### 经典动态规划
- 背包（0-1、完全、多重、分组）
- 区间 DP、数位 DP、状压 DP、树形 DP

### 杂
- 字符串：KMP、Z 函数、Manacher、AC 自动机、后缀数组
- 计算几何：点线、凸包、半平面交
- 位运算工具
