# 数学
## 结论
### 组合数学

- **等差数列求和**   $S_n=na_1+n(n-1)d/2$
- **等比数列求和**  $S_n = a_1(1-q^n)/(1-q)$
- **等比数列性质**  $a_{i-1}*a_{i+1}=a_i^2$   `由于除法会丢精度，所以常用此方法检验等比数列`

### 位运算

- **位加法** $a+b=a \oplus b+2 (a \And b)=a | b + a \And b = 2(a|b)-(a \oplus b)$
- **位减法** $a-b = (a\oplus b) -2(!a \And b)$
- **位运算关系** $a \oplus b = (a |b) -(a \And b)$
- **判断一个数是不是2的幂次** $x \And (x-1)=0$

### 数论

1. 大于2的质数一定是奇数，而奇数一定是偶数+奇数（涉及到加减的质数性质）
2. 对于任何的x 都有$gcd(x,x+1)==1$
3. 质数的幂一定互质
4. 1e9以内的数最多有9个质因子

#### 裴蜀定理 

- 表述1：$ax+by=k*gcd(a,b)$  a和b的线性组合一定是gcd的倍数
- 表述2：$ax+by=m$ 有解当且仅当m是gcd(a,b)的倍数

#### 费马小定理
若 $p$ 为质数且 $\gcd(a,p)=1$，则 $a^{p-1} \equiv 1 \pmod{p}$

#### 欧拉定理
若 $\gcd(a,m)=1$，则 $a^{\varphi(m)} \equiv 1 \pmod{m}$
其中 $\varphi(m)$ 为小于 $m$ 且与之互质的正整数个数

#### 中国剩余定理（CRT）
求解同余方程组（$m_i$ 两两互质）：
$$
\begin{cases}
x \equiv a_1 \pmod{m_1} \\
x \equiv a_2 \pmod{m_2} \\
\vdots \\
x \equiv a_n \pmod{m_n}
\end{cases}
$$
令 $M = \prod m_i$，解为：
$$x \equiv \sum_{i=1}^n a_i \cdot \frac{M}{m_i} \cdot \left(\frac{M}{m_i}\right)^{-1} \pmod{M}$$

#### 威尔逊定理
$p$ 为质数 $\iff (p-1)! \equiv -1 \pmod{p}$
### 卡特兰数

是一类奇特的组合数，前几项为 $1,1,2,5,14,42,132,429,1430,4862$ 。如遇到以下问题，则直接套用即可。

- 【括号匹配问题】 $n$ 个左括号和 $n$ 个右括号组成的合法括号序列的数量，为 $Cat_n$ 。
- 【进出栈问题】 $1,2,…,n$ 经过一个栈，形成的合法出栈序列的数量，为 $Cat_n$ 。
- 【二叉树生成问题】 $n$ 个节点构成的不同二叉树的数量，为 $Cat_n$ 。
- 【路径数量问题】在平面直角坐标系上，每一步只能**向上**或**向右**走，从 $(0,0)$ 走到 $(n,n)$ ，并且除两个端点外不接触直线 $y=x$ 的路线数量，为 $2Cat_{n-1}$ 。

计算公式：$Cat_n=\dfrac{C^n_{2n}}{n+1}$ ，$C_n=\dfrac{C_{n-1}*(4n-2)}{n+1}$ 。

## 快速幂$O(logX)$

```cpp
LL qpow(LL a, int b, int mod){
    LL res = 1 % mod;
    for (; b; b >>= 1, a = a * a % mod){
        if (b & 1) res = res * a % mod;
    }
    return res;
}
```

## 组合数学套餐 （组合 排列 阶乘 逆元 快速幂）

- 重复元素全排列 $\frac{n!}{n_1!n_2!\dots n_k!}$
- 对称性：$C_n^k=C_n^{k-1}$
- 递推式：$C_n^k + C_n^{k-1} = C_{n+1}^k$
- 系数和：$\sum_{i=0}^n C_n^i=2^n$
- 一般隔板（n元素分k组）：  $\boxed{\binom{n-1}{k-1}}$
- 空组隔板（允许隔板之间无元素）  $\boxed{\binom{n+k-1}{k-1}}$

```cpp  
//受限于内存和运行时间，最大可以处理1e8的数据（不会出现爆int的问题）
class Comb // 组合数学套餐 组合 排列 阶乘 逆元 快速幂
{
    vector<int> f;
    vector<int> g;
    static constexpr int mod = 998244353;
public:
	LL qpow(LL a, int b){
	    LL res = 1 % mod;
	    for (; b; b >>= 1, a = a * a % mod)
	        if (b & 1) res = res * a % mod;
	    return res;
	}
    Comb(int n) : f(n + 1), g(n + 1)
    {
        f[0] = 1;
        for (int i = 1; i <= n; i++)
            f[i] = 1LL * f[i - 1] * i % mod;
        g[n] = qpow(f[n], mod - 2);
        for (int i = n; i; i--)
            g[i - 1] = 1LL * g[i] * i % mod;
    }
    int C(int n, int m)
    {
        if (n < m || m < 0)
            return 0;
        return 1LL * f[n] * g[m] % mod * g[n - m] % mod;
    }
    int A(int n, int m)
    {
        if (n < m || m < 0)
            return 0;
        return f[n] * g[n - m] % mod;
    }
    int fac(int x)
    {
        if (x < 0 || x > f.size())
            return -1;
        return f[x];
    }
    int inv(int x) { return qpow(x, mod - 2); }
};
Comb cmb(1e6);
```

## 欧拉筛
### 朴素欧拉筛
```cpp
class sieve{
	vector<bool>st;
	vector<int> primes;
	public:
	sieve(int n){
		st.assign(n + 1, false);
		for (int i = 2;i<=n;i++){
			if(!st[i])primes.push_back(i);
			for (int j = 0; primes[j] <= n / i;j++){
				st[primes[j] * i] = true;
				if(i%primes[j]==0)
					break;
				}
		}
	}
	int find(int x){//找到大于等于x的第一个质数
		return *lower_bound(primes.begin(), primes.end(),x);
	}
};
sieve sv(1e6);
```
### SPF欧拉筛（支持快速质因数分解`O(logn)`，快速质数判断`O(1)`)
```cpp
struct sieve
{
    vector<int> spf;//每个数的最小质因子
    vector<int> primes;
    int n;
    sieve(int _n) : n(_n)
    {
        spf.resize(n + 1, 0);
        spf[1] = 1;
        for (int i = 2; i <= n; i++)
        {
            if (spf[i] == 0)
            {
                spf[i] = i; // 质数的最小质因子是它本身
                primes.push_back(i);
            }
            for (int p : primes)
            {
                if (p > spf[i] || 1LL * i * p > n)
                    break;
                spf[i * p] = p; // 标记最小质因子
            }
        }
    }
    // 质因数分解O(logn)
    set<int> divide(int n)
    {
        set<int> res;
        while (n > 1)
        {
            int p = spf[n], count = 0;
            while (spf[n] == p)
                count++, n /= p;
            res.insert(p);
            // 在这里从小到大分解出了每一个质因数p^count
        }
        return res;
    }
    bool isprime(int x)
    {
        return spf[x] == x;
    }
    int find(int x)
    { // 找到大于等于x的第一个质数
        return *lower_bound(primes.begin(), primes.end(), x);
    }
};
sieve sv(1e6);
```
## 最大公约数 最小公倍数

* **gcd 的线性组合不变量**：对于任何整数集合，它们的 gcd 等于这些整数的所有线性组合的 gcd。也就是说，如果一组数可以通过另一组数的线性组合表示，那么这两组数的 gcd 相同。
	说人话就是：**gcd内部的数可以随意互相加减**

```cpp
int gcd(int a,int b){//返回a和b的最大公约数 O(logn)
	return b ? gcd(b, a % b) : a;
}
int gcd(int a, int b)//异或优化快速gcd
{
	if(b) while(b ^= a ^= b ^= a %= b);
	return a;
}
inline LL gcd(LL a, LL b) // 移位优化最速gcd（速度跟C++17内置gcd相当）
{
#define tz __builtin_ctzll
    a = a < 0 ? -a : a, b = b < 0 ? -b : b;
    if (!a || !b)
        return a | b;
    int t = tz(a | b);
    a >>= tz(a);
    while (b){
        b >>= tz(b);
        if (a > b)
            b^=a^=b^=a;
        b -= a;
    }
    return a << t;
#undef tz;
}
int lcm(int a, int b){
	return a / gcd(a, b)*b;//警示后人:先除再乘防止越界
}
```
## 拓展欧几里得算法
```cpp
int exgcd(int a,int b,int &x,int &y){
    if(!b){
        x = 1, y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= a / b % x;
    return d;
}
```

## 异或线性基
```cpp
struct LinearBasis
{
    int MAXL;
    vector<LL> a;
    LinearBasis()
    {
        MAXL = 64;
        a.assign(MAXL+1, 0);
    }
    LinearBasis(vector<LL> &arr, int _MAXL = 64) : a(_MAXL+1), MAXL(_MAXL)
    {
        build(arr);
    }
    void insert(LL t)
    {
        for (int j = MAXL; j >= 0; j--)
        {
            if (!t)
                return;
            if (!(t & (1LL << j)))
                continue;
            if (a[j])
                t ^= a[j];
            else
            {
                for (int k = 0; k < j; k++)
                    if (t & (1LL << k)) // 消除t中的低位中已占的最高位
                        t ^= a[k];
                for (int k = j + 1; k <= MAXL; k++)//消除高位中t的最高位
                    if (a[k] & (1LL << j))
                        a[k] ^= t;
                a[j] = t;
                break;
            }
        }
    }
    void build(vector<LL>& x){
        a.assign(MAXL, 0);
        for(int i=1;i<x.size();i++)
            insert(x[i]);
    }
    LL queryMax(){
        LL res=0;
        for(int i=0;i<=MAXL;i++)res^=a[i];
        return res;
    }
    void merge(const LinearBasis &other){
        for(int i=0;i<=MAXL;i++)
            insert(other.a[i]);
    }
};
```
